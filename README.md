# Machine Dashboard

## Project Overview

This project is a machine temperature monitoring dashboard built using Python.  
It helps in detecting anomalies in temperature readings using statistical methods.

The dashboard provides interactive visualization of machine data using Plotly.

---

## Project Structure
Machine_Dashboard/
│
├── dashboard.py
├── requirements.txt
├── README.md


---

## Technologies Used

- Python
- Streamlit
- Pandas
- Plotly
- NumPy

---

## Features

- Interactive temperature visualization
- Real-time anomaly detection
- Statistical monitoring using mean and standard deviation
- User-friendly dashboard interface

## Installation & Setup

### 1. Install Python
Make sure Python 3.8+ is installed.

Download Python from:
https://www.python.org/downloads/

---

### 2. Clone or Download Repository

```bash
git clone <repository-link>
cd Machine_Dashboard
3. Install Required Libraries

Run this command inside project folder:

pip install -r requirements.txt

**Run the Project Locally**

Run the dashboard using:

streamlit run dashboard.py

The dashboard will open automatically in your default browser.

If not, open:

http://localhost:8501
